SOAL 2 - INTERNET MELALUI ROOTKIT (IP FORWARDING + NAT)

Tujuan:
Membuat seluruh host internal dapat keluar ke internet melalui rootkit.

==================================================
A. ROOTKIT
==================================================

File:
    /etc/network/interfaces

Tambahkan konfigurasi berikut pada interface WAN eth0:

auto eth0
iface eth0 inet dhcp
    up sysctl -w net.ipv4.ip_forward=1
    up iptables -t nat -C POSTROUTING -s 10.68.0.0/16 -o eth0 -j MASQUERADE 2>/dev/null || iptables -t nat -A POSTROUTING -s 10.68.0.0/16 -o eth0 -j MASQUERADE

Keterangan:
- net.ipv4.ip_forward=1 mengizinkan rootkit meneruskan paket antar-interface.
- MASQUERADE mengganti source IP host internal menjadi IP WAN milik rootkit saat paket keluar.
- Network 10.68.0.0/16 mencakup seluruh subnet internal 10.68.x.x.
- Opsi -C digunakan agar rule MASQUERADE tidak ditambahkan berulang kali setiap interface aktif.

Tidak perlu menambahkan rule NAT terpisah untuk tiap subnet karena seluruh subnet sudah dicakup oleh:
    10.68.0.0/16

==================================================
B. AKTIFKAN LANGSUNG TANPA RESTART (JIKA DIPERLUKAN SAAT DEMO)
==================================================

sysctl -w net.ipv4.ip_forward=1

iptables -t nat -C POSTROUTING -s 10.68.0.0/16 -o eth0 -j MASQUERADE 2>/dev/null || iptables -t nat -A POSTROUTING -s 10.68.0.0/16 -o eth0 -j MASQUERADE

==================================================
C. VERIFIKASI
==================================================

Pada rootkit:
cat /proc/sys/net/ipv4/ip_forward
iptables -t nat -L POSTROUTING -n -v

Target:
- ip_forward bernilai 1
- terdapat rule MASQUERADE untuk source 10.68.0.0/16 menuju eth0

Dari salah satu client, contoh Alpha:
ping -c 3 8.8.8.8

Jika berhasil:
- routing client -> rootkit berjalan
- IP forwarding berjalan
- NAT/MASQUERADE berjalan
- host internal dapat mengakses internet menggunakan IP address

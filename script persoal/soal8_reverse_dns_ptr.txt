SOAL 8 - REVERSE DNS / PTR PADA PRAB DAN TEDD

Domain: k09.com

==================================================
1. KONFIGURASI REVERSE ZONE DI PRAB
==================================================

Edit:

nano /etc/bind/named.conf.local

Tambahkan:

zone "2.68.10.in-addr.arpa" {
    type master;
    file "/etc/bind/db.10.68.2";

    notify yes;
    allow-transfer {
        10.68.3.3;
    };
};

zone "3.68.10.in-addr.arpa" {
    type master;
    file "/etc/bind/db.10.68.3";

    notify yes;
    allow-transfer {
        10.68.3.3;
    };
};

zone "4.68.10.in-addr.arpa" {
    type master;
    file "/etc/bind/db.10.68.4";

    notify yes;
    allow-transfer {
        10.68.3.3;
    };
};

Keterangan:
- Reverse zone dibuat sesuai subnet tempat Abbey, Vault/Core, dan Penny berada.
- Prab menjadi master.
- Transfer hanya diizinkan ke Tedd.

==================================================
2. FILE REVERSE ZONE ABBEY
==================================================

Buat:

nano /etc/bind/db.10.68.2

Isi:

$TTL 86400

@   IN  SOA prab.k09.com. root.k09.com. (
        2026093001
        3600
        1800
        604800
        86400
)

@   IN  NS  prab.k09.com.
@   IN  NS  tedd.k09.com.

==================================================
5. VALIDASI DAN RESTART PRAB
==================================================

named-checkconf
named-checkzone 2.68.10.in-addr.arpa /etc/bind/db.10.68.2
named-checkzone 3.68.10.in-addr.arpa /etc/bind/db.10.68.3
named-checkzone 4.68.10.in-addr.arpa /etc/bind/db.10.68.4
service named restart

Target:
- Semua named-checkzone menghasilkan OK.

==================================================
6. VERIFIKASI REVERSE DNS DI PRAB
==================================================

dig @10.68.3.2 -x 10.68.2.2
dig @10.68.3.2 -x 10.68.3.4
dig @10.68.3.2 -x 10.68.3.5
dig @10.68.3.2 -x 10.68.3.6
dig @10.68.3.2 -x 10.68.3.7
dig @10.68.3.2 -x 10.68.4.2

Target:

10.68.2.2 -> abbey.k09.com
10.68.3.4 -> vault.k09.com
10.68.3.5 -> vault.k09.com
10.68.3.6 -> core.k09.com
10.68.3.7 -> core.k09.com
10.68.4.2 -> penny.k09.com

Keterangan:
- Flag "aa" menunjukkan Authoritative Answer.

==================================================
7. KONFIGURASI REVERSE ZONE DI TEDD
==================================================

Edit:

nano /etc/bind/named.conf.local

Tambahkan:

zone "2.68.10.in-addr.arpa" {
    type slave;
    masters {
        10.68.3.2;
    };
    file "/var/cache/bind/db.10.68.2";
};

zone "3.68.10.in-addr.arpa" {
    type slave;
    masters {
        10.68.3.2;
    };
    file "/var/cache/bind/db.10.68.3";
};

zone "4.68.10.in-addr.arpa" {
    type slave;
    masters {
        10.68.3.2;
    };
    file "/var/cache/bind/db.10.68.4";
};

Keterangan:
- Tedd menarik salinan reverse zone dari Prab.
- File reverse zone di Tedd tidak dibuat manual.

==================================================
8. VALIDASI DAN RESTART TEDD
==================================================

named-checkconf
service named restart

Cek file hasil transfer:

ls -l /var/cache/bind/

Target:
- db.10.68.2
- db.10.68.3
- db.10.68.4

==================================================
9. VERIFIKASI REVERSE DNS DI TEDD
==================================================

dig @10.68.3.3 -x 10.68.2.2
dig @10.68.3.3 -x 10.68.3.4
dig @10.68.3.3 -x 10.68.3.5
dig @10.68.3.3 -x 10.68.3.6
dig @10.68.3.3 -x 10.68.3.7
dig @10.68.3.3 -x 10.68.4.2

Keterangan:
- Hasil PTR harus sama seperti Prab.
- Flag "aa" menunjukkan Tedd menjawab reverse query secara authoritative.

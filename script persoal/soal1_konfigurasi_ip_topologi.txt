SOAL 1 - KONFIGURASI TOPOLOGI DAN IP ADDRESS
Prefix kelompok: 10.68.x.x

Topologi rootkit:
- eth0 -> NAT / WAN
- eth1 -> Switch6 -> alpha, beta, gamma
- eth2 -> Switch4 -> abbey
- eth3 -> Switch1 -> prab, tedd, obladi, desmond, oblada, molly
- eth4 -> Switch5 -> penny
- eth5 -> Switch7 -> delta, epsilon

==================================================
A. ROOTKIT
==================================================

File:
    /etc/network/interfaces

Isi:

auto eth0
iface eth0 inet dhcp

auto eth1
iface eth1 inet static
    address 10.68.1.1
    netmask 255.255.255.0

auto eth2
iface eth2 inet static
    address 10.68.2.1
    netmask 255.255.255.0

auto eth3
iface eth3 inet static
    address 10.68.3.1
    netmask 255.255.255.0

auto eth4
iface eth4 inet static
    address 10.68.4.1
    netmask 255.255.255.0

auto eth5
iface eth5 inet static
    address 10.68.5.1
    netmask 255.255.255.0

Keterangan:
- eth0 menggunakan DHCP karena terhubung ke NAT/WAN.
- eth1 sampai eth5 menjadi gateway untuk masing-masing subnet internal.
- rootkit tidak diberi default gateway pada interface internal.

==================================================
C. VERIFIKASI DASAR
==================================================

Pada setiap node:
ip -br a
ip route

Contoh dari Prab:
ping -c 3 10.68.3.1

Keterangan:
- Default gateway setiap host adalah IP interface rootkit pada subnet yang sama.
- Switch bukan gateway; switch hanya meneruskan frame di Layer 2.
